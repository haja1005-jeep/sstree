# 📍 내 주변 한눈에

앱을 켜면 현재 위치 기준으로 가장 가까운 **주유소·음식점·카페·숙박·렌트카·택시·지하철역/출구·랜드마크**를 거리순으로 자동 표시합니다. (카카오 로컬 API + 카카오맵)

- 다른 도시·장소는 검색창에서 입력 (예: 제주공항, 부산역) → 해당 지점 주변 표시
- 카테고리 칩으로 필터, 반경 1/2/5/10km, 결과가 적으면 자동 확대
- 목록 탭 → 지도 이동, "길찾기" → 카카오맵 길찾기
- PWA: 모바일에서 "홈 화면에 추가"로 앱처럼 사용

## 설정 (필수)
1. https://developers.kakao.com 에서 앱 생성
2. 앱 키 > **JavaScript 키**를 `config.js`의 `KAKAO_JS_KEY`에 입력
3. 플랫폼 > Web 에 사용 도메인 등록 (로컬 테스트: `http://localhost:8080`)
4. 제품 설정 > **카카오맵** 사용 설정 ON

## 실행
위치 권한은 HTTPS 또는 localhost에서만 동작합니다.
```
cd nearby && python3 -m http.server 8080
```
JavaScript 키는 도메인 제한으로 보호되는 공개용 키입니다(REST 키는 쓰지 않습니다).

## 카테고리 매핑
주유소 OL7 · 음식점 FD6 · 카페 CE7 · 숙박 AD5 · 지하철역 SW8(+"지하철 출구" 키워드) · 관광명소 AT4 / 문화시설 CT1 · 렌트카·택시는 키워드 검색(카카오에 전용 코드 없음)
