# 📍 내 주변 한눈에

앱을 켜면 현재 위치 기준으로 가장 가까운 **주유소·음식점·카페·숙박·렌트카·택시·지하철 출입구·랜드마크**를 거리순으로 자동 표시합니다.

- 서버·API 키 불필요 (OpenStreetMap Overpass / Nominatim / Leaflet)
- 다른 도시·장소는 검색창에서 입력 (예: 제주공항, 도쿄역) → 해당 지점 주변 표시
- 카테고리 칩으로 필터, 반경 1/2/5/10km, 결과가 적으면 자동 확대
- 목록 탭 → 지도 이동, "길찾기" → 도보 길안내
- PWA: 모바일에서 "홈 화면에 추가"로 앱처럼 사용

## 실행
위치 권한은 HTTPS 또는 localhost에서만 동작합니다.
```
cd nearby && python3 -m http.server 8080   # http://localhost:8080
```
GitHub Pages 등 정적 호스팅에 폴더째 올리면 바로 사용 가능합니다.
